# Tutorial SortTrip

Video vertikal 720×1280 (9:16), 60 detik, MP4 H.264, 15fps, teks bahasa Indonesia tanpa narasi/audio. Dibuat dari tangkapan UI production 24 Oktober 2026 dengan transisi dan indikator waktu.

Contoh pencarian: Hanoi; contoh itinerary: Kuala Lumpur. Harga adalah contoh indikatif pada waktu pengambilan, bukan tarif terkunci. Instruksi Assistant ditampilkan tanpa menjalankan generasi baru; tidak ada pembayaran, prebook, reservasi, atau penyimpanan perubahan itinerary.

Alur: Jelajahi → inspirasi → pengaturan pencarian → penerbangan → Assistant → detail/rute → tinjau booking dan kunci item → penutup. Format ini berupa panduan visual dengan teks; bukan rekaman layar interaktif tanpa potongan.
